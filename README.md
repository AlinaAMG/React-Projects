
## 🛒 Shopping Cart met React (useReducer + Context API)


## Live Demo
https://cart-app-use-reducer.netlify.app/


![React-app](https://github.com/AlinaAMG/React-Projects/blob/cart-useReducer/src/assets/cart.jpg)

Dit project is een eenvoudige shopping cart applicatie gebouwd met React, waarbij gebruik wordt gemaakt van de useReducer hook en Context API.
De cart bevat een lijst met telefoons, en je kunt items beheren (toevoegen/verwijderen, aantal aanpassen) en het totaalbedrag berekenen.

🚀 Functionaliteiten

📱 Lijst met telefoons wordt getoond in de cart.

➕ Increase/Decrease: pas het aantal van een telefoon aan.

❌ Remove Item: verwijder een specifieke telefoon uit de cart.

🧹 Clear All: leeg de hele cart in één klik.

💰 Totaal Price: de totale prijs van alle telefoons in de cart.

🛠️ Gebruikte tools en technieken

React (functionele componenten)

useReducer hook voor state management

Context API om de cart state door te geven aan componenten

JavaScript ES6+ features

CSS voor basis styling (optioneel)
