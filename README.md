 ### React Menu App

 ![React-App](https://github.com/AlinaAMG/React-Projects/blob/menu-app/public/images/menu.jpg)

 

### Een simpele React applicatie die een lijst met gerechten toont.  
Je kunt filteren op categorieën zoals **all**,  **breakfast**, **lunch** en **shakes**.  

## 🚀 Functionaliteiten
- Dynamisch laden van menu-items uit een dataset
- Weergave van gerechten met **titel, prijs, afbeelding en beschrijving**
- **Filterknoppen** waarmee je gerechten per categorie kunt bekijken
- Responsive design (werkt op desktop en mobiel)

## 🛠️ Gebouwd met
- [React](https://react.dev/) (Vite)
- JavaScript (ES6+)
- CSS voor styling
