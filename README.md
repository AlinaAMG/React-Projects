

# 📱 Redux Toolkit Winkelmand App

Kijk Live https://reduxtoolkit-app.netlify.app/

![Redux/toolkit](https://github.com/AlinaAMG/React-Projects/blob/redux/toolkit/public/cart.png)


Dit project is een moderne winkelmand-applicatie gebouwd met **React** en **Redux Toolkit**.  
De app haalt een lijst van telefoons op van een **externe API** met behulp van `createAsyncThunk`, en laat de gebruiker producten beheren in een interactieve winkelmand — compleet met SVG-iconen, hoeveelheid-aanpassing en een bevestigingsmodal.

---

## 🚀 Functies

- 📡 **Data ophalen van een externe API** via `createAsyncThunk`
- 🛍️ **Telefoonlijst tonen** in de gebruikersinterface
-  **Verhoog of verlaag de hoeveelheid** van elk item met svg-iconen
  (de totale prijs past zich automatisch aan)
- 🗑️ **Verwijder een item** wanneer de hoeveelheid teruggaat naar 0
- ⚠️ **Verwijder alle items tegelijk** met een bevestigingsbericht (gemaakt via `modalSlice`)
- 💰 **Automatische berekening van totaal aantal items en totale prijs**
- 🧩 **State management met Redux Toolkit**
- 🖼️ **SVG-iconen** voor knoppen (zoals plus, min, verwijderen)
- 🪄 **Netjes gestructureerd met aparte slices en store**


## 🧠 Gebruikte technologieën

- **React** – Gebruikersinterface  
- **Redux Toolkit** – Voor eenvoudige state management  
- **createAsyncThunk** – Voor asynchrone data-opvraging  
- **Fetch API** – Voor communicatie met externe API  
- **React-Redux** – Voor koppeling tussen React-componenten en de store  
- **SVG-iconen** – Voor duidelijke, moderne UI-knoppen
