### Sidebar-Modal-app

![React-app](https://github.com/AlinaAMG/React-Projects/blob/modal-sidebar/src/assets/sidebar-modal.jpg)

Dit project is een voorbeeld van een **React applicatie** met een **sidebar** en een **modal**, gebouwd met moderne tools en patterns.  
Het project gebruikt **React Context** om de state van de sidebar en modal centraal te beheren, en maakt gebruik van **React Icons** voor visuele iconen.  

## ✨ Features

- **Sidebar**
  - Toggle met een **hamburger-menu** (openen/sluiten).
  - Bevat navigatielinks en iconen.
  - Links worden dynamisch geladen via een data-array en gemapt in de sidebar.

- **Modal**
  - Kan geopend worden met een button.
  - Wanneer de modal open is, wordt de achtergrond **grijs** gemaakt (overlay effect).
  - Kan gesloten worden via een **X-icoon**.

- **React Context**
  - Beheert de open/dicht state van de sidebar en de modal.
  - Zorgt ervoor dat de state overal in de app beschikbaar is.

- **CSS Toggle Classes**
  - Openen en sluiten van de sidebar en modal gebeurt met **CSS classes** (`open`, `close`).
  - Smooth transitions met CSS animaties.
