### Review Carousel App

Dit project is een kleine React-applicatie waarin gebruikers door reviews  kunnen bladeren. De app toont telkens een persoon met naam, job, afbeelding en tekst. Met knoppen kun je vooruit, terug of een willekeurige persoon selecteren.

🚀 Functionaliteiten

Volgende & vorige review: blader door de lijst van personen.

Random persoon (Surprise Me): kies een willekeurige review.

Looping: wanneer je aan het einde van de lijst bent, ga je automatisch terug naar het begin (en omgekeerd).

React state management: de huidige index wordt bijgehouden met useState.

📂 Structuur

index.js of App.js: bevat de hoofdcomponent met de logica.

people.js: een array met objecten van personen (naam, job, afbeelding, tekst).


🛠️ Gebruikte technieken

React (useState hook voor statebeheer).

JSX voor component rendering.

React Icons (FaChevronLeft, FaChevronRight, FaQuoteRight) voor iconen.
