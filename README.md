
# Grocery Bud 🛒

https://github.com/AlinaAMG/React-Projects/blob/grocery-bud/src/assets/grocery-bud.jpg

Een eenvoudige maar krachtige React-app waarmee je boodschappen kunt beheren.  
Gebruikers kunnen items toevoegen, markeren als voltooid, verwijderen en alles blijft bewaard in **Local Storage** (ook na een refresh van de pagina).  
De app is volledig **responsief** en geeft duidelijke meldingen met behulp van **React Toastify**.

---

## ✨ Features
- ➕ **Items toevoegen** met een formulier (input + button)  
- ✅ **Items markeren** als "done" met een checkbox  
- ❌ **Items verwijderen** met een delete-knop  
- 📝 **Edit functionaliteit** via checkbox toggle  
- 💾 **Persistentie via Local Storage** → items blijven ook na een refresh  
- 🔔 **React Toastify meldingen** voor acties (toevoegen, verwijderen, fouten)  
- 🎨 **Custom CSS styling** en volledig **responsief**  

---

## 🛠️ Tech Stack
- **Vite + React** (snelle bundler en moderne React setup)
- **React Toastify** (notificaties)
- **Local Storage API**
- **CSS3** (custom styling + responsive design)
