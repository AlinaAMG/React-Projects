

## Color Generator App

![React-App](https://github.com/AlinaAMG/React-Projects/blob/color-generator/src/assets/color.jpg)

   Een interactieve React-app waarmee je automatisch kleurenschaduwen genereert van een opgegeven kleur. De app is volledig gestyled met CSS en responsive, zodat hij op elk scherm goed werkt.
   
De app gebruikt moderne React-bibliotheken zoals React Toastify voor meldingen en nanoid voor unieke ID’s.

## 🛠 Features

Kies een kleur via color input.

Klik op Generate om automatisch de eerste 10 schaduwen van die kleur te genereren (van 10% tot 100%).

Elke schaduw heeft een unieke ID via nanoid.

React Toastify toont success- en errormeldingen

CSS styling zorgt voor een nette UI.

Responsive design → werkt goed op desktop, tablet en mobiel.


## 💻 Technologieën & Libraries

React.js – frontend framework

React Toastify – voor notifications

nanoid – unieke ID’s voor elke kleur

values.js – om kleurenschaduwen te berekenen

CSS – styling van componenten

Responsive design – mobile-first layout
