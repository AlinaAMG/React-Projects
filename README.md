🎠 React Carousel App

![React-App](https://github.com/AlinaAMG/React-Projects/blob/carousel-slider/src/assets/slider.jpg)

Een responsive Carousel applicatie gebouwd met React, waarin data wordt geladen uit een apart bestand (data.js).

De app bevat twee versies:

1.Custom Carousel met React Hooks
Handmatige implementatie met useState en useEffect
React Icons voor de Prev en Next knoppen

2.Carousel met react-slick
Gebouwd met de populaire react-slick slider library
Ondersteunt automatische sliding en meer features out-of-the-box


✨ Features

📷 Toont afbeelding, naam, titel en tekst uit data.js

⬅️➡️ Vorige en Volgende knoppen met React Icons

🎨 Gestyled met CSS voor een modern design

📱 Responsive layout (werkt goed op desktop, tablet en mobiel)

🔄 Twee implementaties beschikbaar:

Custom carousel met React Hooks

Carousel met react-slick
